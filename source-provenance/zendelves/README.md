# Zendelves reuse

Repository: `eyehaveewe-cyber/Zendelves`

Pinned source commit: `357aa0f77b0c8080074745e3f56b2a7a78241d04`

`actor-models.ts` is preserved from `lib/xen/actor-models.ts`, blob `df885e580b61f45eea04877a72cd54417090b10b`. It has no external imports. The seven JSON files under `assets/models` are generated by executing its original constructors. The researcher uses `createMonkParts()` with the staff removed; the six creature shapes use the spider, octopus, plant dog, slime dog, bat and dryad constructors. Klax recolors these meshes at runtime and adds the researcher's backpack and helmet.

`scripts/creature_models.gd` ports the limb gait, rear-leg phase inversion, tail and wing motion from `lib/xen/renderer.ts`, blob `0e410ec8d71e1a3b9ae88fc85f58123e77c90de1`, lines 165–171 at that commit. Vertices stay local to the original pivot. Parts sharing a joint name keep their individual pivots.

`PROVENANCE.json` lists the additional source files inspected during extraction. Those broader game, status and renderer files are reference material; they are not imported into Klax at runtime. The terrain, stations, flora and expedition layouts in `scripts/world.gd` are new Klax code.

Regenerate the mesh files from this directory with:

```sh
node --experimental-strip-types export-models.mjs
```

The export and native Godot model construction both ran successfully. The source contains the original author's code; this file does not grant a new license.
